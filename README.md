# 中日双语高情商话术库

收录《高情商回复日语》及后续聊天截图问答中的日文话术和配套中文译文。每条话术保留原有措辞、段落和表情。

## 按场景查找

| 场景 | 可以找到的话术 |
| --- | --- |
| [餐饮店工作](categories/restaurant-work.md) | 对方提到在餐饮店工作时，体谅忙时的辛苦，接着聊工作内容。 |
| [兼职领班](categories/shift-lead.md) | 对方说自己是兼职领班时，回应他的责任和付出，或自然地聊到排班。 |
| [礼貌关怀](categories/polite-care.md) | 想向对方道一声辛苦时，可以选择详细的回应或简短的聊天版本。 |

## 给读取话术的 AI

[dialogues.json](dialogues.json) 是 UTF-8 编码的数组，每个 `id` 对应一条完整话术。按 `categories` 筛选场景，成对读取 `ja`（日文）和 `zh`（中文）。同一条话术可以出现在多个分类页。

`source` 区分原对话中的回复与附图中已有的双语消息。餐饮店条目的中文沿用截图所示译文。
