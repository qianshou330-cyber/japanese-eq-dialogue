# 账号核对与身份验证

## 对方把姓名当成 PayPay ID 时，协助核对收款账号

`account-verification-001` · 对话中的双语回复

**日文**

経緯を教えてくださってありがとうございます。担当の方にもご連絡くださったんですね。

PayPay IDは相手を検索するためのものですので、お名前と違っていても、それだけで入力ミスとは限りません。念のため、お伝えいただいたIDが、PayPayアプリの「アカウント」に表示されているIDと合っているか、お手元でご確認いただけますか？

PayPayの本人確認のために、追加のタスクや送金をしていただく必要はありません。本人確認が必要な場合は、PayPayアプリ内の案内に沿ってお手続きください。身分証の画像や認証コードは、このチャットには送らないでくださいね。

**中文**

谢谢您说明事情的经过，我知道您也已经联系过负责人了。

PayPay ID 是用来搜索对方账号的，和您的姓名不同，并不代表您输错了。为稳妥起见，麻烦您自己核对一下，之前告知的 ID 和 PayPay 应用里「アカウント」（账户）页面显示的 ID 是否一致，好吗？

验证 PayPay 身份无需再做任务，也无需转账。如果确实需要验证，请按 PayPay 应用内的提示办理。请不要在这个聊天里发送身份证件照片或验证码。

参考：[PayPay ID 说明](https://paypay.ne.jp/help/c0096/) · [PayPay 本人确认指南](https://paypay.ne.jp/guide/auth/)
